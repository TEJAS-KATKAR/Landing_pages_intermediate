# Elementum Landing Page

A responsive landing page built using React and CSS, inspired by a modern agency-style design. This project was created to practice frontend development, responsive layouts, UI implementation, and deployment workflows.

## Live Preview

https://landing-page1016.vercel.app/

## Features

* Responsive design for desktop, tablet, and mobile devices
* Clean and modern UI
* Custom hover animations and interactions
* Reusable React components
* Optimized image assets
* Deployed with Vercel

## Tech Stack

* React
* Vite
* JavaScript
* CSS3
* HTML5

## Project Structure

* Hero Section
* About Section
* Services Section
* Testimonials Section
* Newsletter Section
* Footer

git clone <repository-url>
